COMBAT UI CONCEPTS

사이드뷰 전투 화면입니다. 캐릭터는 왼쪽, 열차는 오른쪽, HUD는 좌상 스탯 · 우상 연타 · 하단 힌트입니다. 각 안은 같은 배치에 UI 키트만 다릅니다. 글자는 이미지에 넣지 않았습니다.

1. 유리

반투명 남색 유리, 얇은 금 테두리.

2. 승차권

크림 티켓, 절취선, 남색 아웃라인.

3. 네온

홀로그램 시안 라인 HUD.

4. 플랫

흰 카드, 검은 선. 낮 철교.

5. 전술

올리브 와이어프레임, 화물 조차장.

6. 금 유리

남색 필리그리. 현재 인게임에 가장 가깝습니다.
