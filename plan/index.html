등굣길을 들이받아 이세계로 보내는 열차를, 학생회가 선로에서 막는다.

웹 광고형 하이브리드 캐주얼 · 가로 16:9 · 2026-09-18 기준

플레이 전투 UI 컨셉

1. 한 줄

사이드뷰 연타 디펜스. 주인공은 자리를 지키고, 열차와 이세계 개체만 다가온다. 들이받으면 게임오버.

2. 세계관

시간표에 없는 열차가 학생을 들이받는다. 맞은 사람은 이세계로 사라진다. 차체에서 이세계 개체가 내린다. 막으면 다음 열차가 온다.

막기 위해 학생회 임원이 선로에 선다. 플레이어는 회장, 옆에서 쏘는 동료는 부회장, 열차를 몸으로 막는 이는 체육부장이다.

3. 캐릭터

역할내용
학생회장플레이어. 인식표, 권총. 타이틀에서 기본 선택.
부회장빨간 완장. 런 중 상점 동료(자동 사격). 최고 5스테이지 클리어 시 타이틀에서 플레이어로 선택 가능.
체육부장열차를 몸으로 막아 속도를 줄인다. 일회성. 상점에서 구매·강화.

4. 전투

  • 가로 16:9. 캐릭터는 왼쪽, 열차는 오른쪽에서 접근.
  • 조작은 화면 연타(또는 스페이스). 연타에 샷 사운드와 햅틱을 묶는다.
  • HUD: 좌상 스테이지·체력·거리·골드·탄약, 우상 연타, 하단 힌트.
  • 1스테이지는 이세계 개체(좀비)가 반드시 나온다. 광고와 첫 판이 같아야 한다.
  • 스테이지를 막으면 비품실 → 다음 열차.

5. 런 밖

  • 내일 출근 — 오늘 첫 런에서 출근 스트릭을 기록한다. 이어지면 골드 보너스(최대 50G). 하이점수만으로는 재방문이 안 되므로 타이틀에 둔다.
  • 캐릭터 해금 — 5스테이지 클리어 시 부회장. 타이틀에서 회장/부회장 선택.

7. 채널 · 측정

  • 채널은 웹 하나. 스팀 저가와 병행하지 않는다. 둘 다 하면 둘 다 약해진다.
  • 측정 없이 UA 금지. 설정에 방문, 1스테이지 시작·클리어율, D1 복귀를 둔다.

8. 화면

플레이 창은 가로 16:9 (최대 1920×1080). 모바일은 가로 모드를 기준으로 한다.

10. 열린 결정

  • 전투 UI 키트 9 채택. 홈·상점 판은 같은 철제+일러스트 톤으로 맞춤.
  • 실제 광고 SDK는 스텁(+60G) 이후.
  • 방문·1스테이지 클리어율·D1이 나오기 전에는 UA를 쓰지 않음.

이 문서는 현재 빌드와 합의된 결정만 적는다. 컨셉 이미지는 선정 전까지 참고다.
